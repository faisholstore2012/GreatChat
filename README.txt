GREAT CHAT ONLINE - FIXED VERSION
================================
Versi ini TIDAK memakai better-sqlite3, jadi tidak membutuhkan Python atau compiler C++ untuk npm install.

Cara menjalankan:
1. Buka folder ini di VS Code.
2. Terminal:
   npm.cmd install
3. Setelah selesai:
   npm.cmd start
4. Buka http://localhost:3000

Data akun/chat disimpan di data.json.
File upload disimpan di uploads/.
Untuk produksi/public, gunakan database server seperti PostgreSQL dan storage yang persisten.
